## 启动与实例复用

Windows 可双击 `scripts/run.cmd`。重复启动会复用同一配置的现有服务；检测到源码变化时，提示确认后构建新版，等待现有调用结束再切换。等待超时保留旧服务，切换期间可能短暂返回 503。

修改配置后使用 `pwsh -File scripts/run.ps1 -Restart` 明确重启。多个独立实例应隔离数据及渠道凭据目录，Qoder 可通过 `QODER2API_HOME` 设置。不要删除 `.instance.lock` 或强杀不明端口进程，崩溃后操作系统会释放实例锁。

## 版本更新

管理台「设置」支持检查稳定版、手动安装及定时策略。定时任务默认关闭，可选仅提示或维护窗口安装。

| 部署来源 | 更新方式 |
|---|---|
| 正式 Release 二进制 | 条件满足时在管理台安装 |
| 源码自行编译 | 使用原构建与启动脚本，管理台仅检查 |
| Actions 临时提交产物 | 下载新的提交产物手工部署，管理台仅检查 |
| Docker | 拉取新镜像并重建容器，保留数据卷 |
| systemd | 当前内置安装要求 root 身份、服务归属核验及程序目录可写；低权限服务由部署工具更新 |

安装能力依据构建来源识别，修改版本字符串不会开启。程序目录需可写，早期不带发布标识的版本需先手工升级。

自更新会校验下载包、生成完整备份并保留旧程序，最多等待现有调用 60 秒。等待超时保留旧服务，新版检查通过后恢复接单。切换不是零停机，管理登录可能需要重新进行。

管理台只允许检查更新时，先查看更新状态中的部署类型和原因；不要仅为启用安装按钮将低权限服务改为 root。

自动安装仅接受数据库版本不变的稳定版，迁移需手动确认；自动安装同版本重发产物默认关闭。更新日志与恢复副本位于数据目录 `.updates/`，含敏感数据，不得公开。新版可能已接收请求或状态不明时，不要直接覆盖数据库。

## 备份与恢复

在设置中手动生成在线完整备份，或启用每日自动任务。自动任务默认关闭，保留最近 7 份校验成功的归档，不删除手工备份。

完整备份包括数据库、主密钥、各渠道凭据和有效配置，保存至 `DATA_DIR/backups`。额外文件可通过 `BACKUP_EXTRA_PATHS` 指定。凭据 JSON 导出仅用于账号迁移，不能替代完整备份。

恢复时先在隔离目录核验归档，正常停止目标服务，再恢复匹配的程序、数据和配置。数据库与 `.secret_key` 必须配套迁移；涉及数据库升级的回退不能只换旧程序。启动后检查登录、Key、模型目录及账号归属。

## 调用记录与续航

流量页展示模型与实际渠道、Tokens、思考和缓存细分、性能、消耗及结束状态；详情关联各次尝试和请求 ID。门户仅展示本人记录。

- 首生成表示网关观察到首次有效思考、正文或工具增量的时间。
- 生成速度按输出 Tokens 与观察到的生成阶段耗时计算，包含思考及工具输出。
- 缺少生成观测时展示首响应与整次平均速度，未上报字段显示 `—`。
- 思考属于输出总量、缓存读取属于输入总量，不重复累加；不同渠道的消耗单位不直接比较。

管理员可按流量日志的当前筛选条件生成 CSV，完成后点击下载。每次最多生成一份，生成上限为 2 分钟或 128 MiB，文件最多保留 15 分钟。超时或文件过大时可缩小筛选范围重试。

概览按同价账号的有效余额、近期付费用量及实际消费估算续航。不同计费规则与余额适用范围分开计算，免费用量另计。首页标记部分覆盖，明细可查看模型构成、账号余额和最近到期的金额。

在设置中按需启用签到、额度和模型目录刷新。记录保留见 [配置说明](configuration.md)，部署连接见 [部署说明](deployment.md)。

## 账号健康

账号页区分可调度、待验证、冷却、停用和授权异常，悬停或点击状态可查看原因、恢复时间及最近调用结果。可调度不保证每个模型都能成功；零积分也不一定影响免费模型。

手动停用只停止模型调度，仍参与已启用的签到与维护；维护成功不会自动启用账号。确认登录失效的凭据退出选号，包括会话粘性；单个模型目录或额度接口鉴权失败只暂停对应维护，不据此判定整号失效。账号状态用颜色提示，详情气泡解释范围和恢复方式。授权异常会暂停相关维护：暂时故障退避后先验证授权，明确失效则等待重新授权。健康详情中可查看暂停原因与恢复检查时间。

额度刷新失败时保留上次余额。只有授权异常才提示重新授权，网络或上游服务故障不等于登录失效。最近调用状态属于本次运行的观察，重启后没有记录时显示未知。

账号页「测活」提供只读检查和指定模型真实测试，也可批量检查所选账号。定时检查默认每 30 分钟运行，可在设置中关闭或调整间隔；复用近期维护结果并错峰执行，不增加模型调用限额。手动测试可能消耗额度，只命中指定账号，不计入用户流量和续航样本。

检查结果只代表标注的范围：授权或目录验证通过不保证所有模型可调用，OpenCode 公开目录可达也不能证明 Key 有效。健康气泡显示检查时间、原因及所测模型；结果过期后需重新验证。重启后重新建立检查观察。

## 常见问题

| 现象 | 先检查 |
|---|---|
| 门户提示拒绝跨源请求 | 外部域名与回源 Host 是否一致，旧配置是否覆盖自动策略 |
| 代理返回 HTML 502 | 代理 / Tunnel 的回源地址、端口和 HTTP / HTTPS 协议 |
| 应用提示发起登录失败 | 授权上游连通性及所选渠道 / 区域 |
| Trae 授权回调无法访问 | 浏览器到回调地址是否可达，使用授权窗口的手工回调入口 |
| 请求返回 413 | 请求体大小及 `MAX_REQUEST_BYTES`，与模型上下文 Tokens 上限分别检查 |
| 一直“正在思考”或输出未完成 | 日志中的首生成、思考 / 输出 Tokens、输出预算及结束原因 |
| Key 或模型不可用 | Key 白名单、用户权限、全局禁用及账号状态 |
| 端口占用 | 使用启动脚本复用同一配置的实例，或正常停止后重启 |

反馈问题时提供版本、客户端、协议、模型、失败时间和网关请求 ID，不发送 Key、Cookie 或完整私人对话。安全软件拦截未签名程序时，先核对下载来源、校验值及具体拦截记录。
