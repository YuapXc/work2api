# 渠道接入

[返回项目首页](../README.md)

在管理台「账号」页选择渠道并添加凭据。各渠道独立配置，调用模型以模型页或 `/v1/models` 返回的真实 ID 为准。

| 渠道 | 接入方式 | 模型前缀 |
|---|---|---|
| WorkBuddy / CodeBuddy，国内与国际 | 扫码授权、凭据文件导入 | `workbuddy/`，兼容裸 ID |
| Qoder，国内与国际 | 扫码授权、个人 PAT、Windows 本机凭据探测 | `qoder/` |
| OpenCode Zen / Go | 个人 API Key、可选匿名入口 | `opencode/` |
| 国内 Trae IDE / Work-SOLO | 网页授权、JSON 导入、本机登录态导入 | `trae/` |

## WorkBuddy / CodeBuddy

支持多账号、成本与额度感知、会话粘性和故障切换，国内账号提供签到。桌面凭据无法解密时，改用网关扫码授权。

## Qoder

管理员可设置优先激活账号，可重试故障时切换其他符合区域和模型要求的账号。用户贡献不改变管理员激活账号。

除了 `qoder/` 下的模型 ID，也可填写账号目录中的显示名，例如 `qoder/Qwen4-Max-Preview`。网关按实际模型检查权限；同一显示名对应多个获准模型时，请使用 `/v1/models` 返回的 ID。手动配置的模型映射优先。

Windows 可探测本机已登录凭据；无法解密时改用扫码授权。国内签到和额度刷新可在管理台开启，国际签到尚未支持；PAT 不支持设备令牌额度查询。

Qoder 返回可查询的排队状态时，网关可等待放行后继续调用；流式等待期间发送心跳。确认队列停滞或排队等待预算耗尽后，可在尚未输出且请求仍有效时尝试其他有权限账号。排队超时会说明原因，客户端取消立即停止，已输出的回答不会重放。 管理员可在请求日志详情查看累计等待、状态查询次数、队列人数及最后等待结果；仅记录状态摘要。

## OpenCode

在「编辑配置」中设置 Zen / Go Key 和匿名入口，保存后生效。也可使用 `OPENCODE_CONFIG` 指定配置路径。

官方匿名入口自动使用 `/inference`；自定义端点保持原地址，也可通过 `upstream.anonymous` 单独指定。可选的 `performance.attempt_timeout_seconds` 只限制连接至首次有效流事件的等待，默认不额外限制，流开始后沿用整次请求超时。

管理员可在账号页的 OpenCode 配置中使用官方设备授权登录 Go 订阅，并选择订阅所在组织。授权、续期和凭据保存由后端完成；配置重载无需重新登录。启用订阅登录时暂停手动 Go Key 备用，断开后恢复；订阅调用失败不会自动切换到按量付费通道。

Go 订阅只发布官方授权返回的模型与接口，额度显示为未知，不推算剩余订阅量。凭据保存在 OpenCode 配置旁的 `.go-oauth.json` 文件中，在线备份会包含该文件。

不提供签到。匿名入口是系统资源，用户只能贡献个人 Key，Go 订阅授权由管理员管理。模型页价格为参考价，实际消费以对应通道账单为准。

## Trae

国内 IDE 与 Work/SOLO 分别授权、读取各自模型目录，同一上游用户共用账号归属和余额资源。国际版尚未接入。

企业账号在授权时选择「企业账号」，从企业控制台登录。账号目录里已启用的企业内置聊天模型可直接调用；网关使用该模型的身份和输出上限。企业控制台按席位额度展示和调度；明确收到 4245 且尚未输出时，可切换到个人网关，并记住该账号的选择。个人网关使用个人 Credits，另一类额度仅作参考，两者不混算。

实时目录明确支持且窗口更大时，默认启用 Trae Max 大窗口；可在设置页的 Trae 选项中关闭，模型目录与实际请求同步切换。更大窗口允许更多输入，实际消费以上游计费为准。

企业自定义模型的目录若提供受支持的专用端点与配套 Key，优先按官方客户端方式直连；登录 JWT 不会发送到专用端点，专用 Key 不对模型目录或日志公开。输出前失败时可在本次尝试预算内回退企业网关，输出开始后不会重放。管理员可在请求日志中区分企业控制台、企业模型直连与个人网关路线。

远程部署时，浏览器无法直达回调地址可按授权窗口提示手工提交回调。自动签到和额度刷新可在管理台开启；签到经上游确认后显示已知奖励金额；未返回金额时不估算。未确认的模型价格不展示为免费。调用采用聊天与调用方工具模式，不启用上游远程 Agent。

用户贡献与撤回规则见 [用户门户](portal.md)，完整迁移使用 [在线备份](operations.md)。

## 模型信息

模型页展示上游确认的上下文、输出上限、图片与工具能力、思考档位和成本信息。WorkBuddy 优惠规则按区域及账号适用范围展示，优惠标签不承诺本次调用免费。

Trae 成本系数读取目录当前倍率，已含上游当前优惠；多账号或产品倍率不同时显示范围，优惠时段可在标签气泡中查看。倍率不是每百万 Tokens 单价，缓存过期或字段缺失时不推断价格。

成本系数仅在对应渠道内比较，未知价格显示 `—`，不能视为免费。资源包余额与到期时间在账号页查看，临期额度会提示。


## 流式与目录兼容

WorkBuddy 的「合并思考碎片」默认开启，可在设置页关闭。首段思考立即发送；后续按 300 毫秒、8 KiB 或块结束刷新。正文、工具、用量及结束事件保持顺序，大帧和多候选帧原样转发。原生 Messages 与非流式调用沿原链路处理。符合长期 Token 条件的可续期登录会提前续期；失败时退避，仍有效的访问 Token 不因一次提前续期失败而被丢弃，已确认授权失效的处理规则不变。

Qoder 在确认排队时登记对应请求租约，结束、取消或放弃后按官方协议尽力释放；释放最长 3 秒且不阻塞响应。恢复要求同时满足不再排队和服务未明确不可用。桌面设备身份使用配套的客户端版本与聊天声明，旧 IDE 身份保留原协议；这些兼容不能代替失效账号重新授权。

Trae 企业 Token 的 SaaS 标记可位于顶层或 `data.scope`，顶层明确值优先。只有与预设重名的企业模型使用 `provider//config_name` 区分，发往上游的仍是原配置名及企业来源；未重名模型不批量改名。明确 4026 窗口拒绝时，可在原尝试预算内换其他有权账号，保留完整历史；不冷却整个账号，也不把其他账号的实测窗口统一当成固定上限。

Trae 的「回填已结算用量」默认关闭，仅用于国内个人网关，不用于企业席位金额或专用端点直连。开启后，流式查询预算为 400 毫秒，非流式为 2.5 秒，单次查询最多 2 秒；拒绝不重试，未更新账单有限等待。按账号、产品和会话保存有界累计基线，只在能归属当前调用时回填积分和缓存；并发重叠、回退、未结算及缺失字段保留未知，不把它们记为零消耗。正的上游缓存读数优先。查询失败不影响已生成回答，关闭时不发账单请求。
